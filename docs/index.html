// 01 — 工作方式

浏览器 → 采集 → AE/PS，三步完成

不用下载、不用找文件、不用拖拽。在网页上看到任何媒体素材，直接发送到创作工具。

01

智能嗅探

浏览器扩展自动扫描页面上的图片、视频、音频，同时拦截网络请求捕获隐藏的媒体 URL。支持 HLS、DASH、FLV 等流媒体协议。

02

快捷采集

Ctrl+Shift+右键 呼出采集面板，预览媒体、编辑文件名、选择目标。支持批量采集，一次选中多个资源统一发送。

03

一键导入

通过 WebSocket 实时通信，直接将素材导入 AE 合成或 PS 文档。支持图层位置、时间范围、预合成包装等精细控制。

// 02 — 核心特性

为创作者打造的采集利器

不只是「下载工具」——是从浏览器到创作画布的完整桥梁。

Action Orbit 轨道菜单

长按"发送"按钮打开圆形渐进式菜单，一次手势完成"存哪 → 放哪 → 怎么放 → 是否包装"全部决策。松手于无效区域自动取消，安全可靠。

长按 380ms→选择磁盘行为→选择 AE 目标→确认图层选项→松开执行

双宿主支持

同一扩展同时服务 After Effects 和 Photoshop。浏览器 popup 一键切换目标宿主，各自独立的 WebSocket 通道。

流媒体解析

内嵌 hls.js 和 mpegts.js，直接在浏览器中解析 HLS (m3u8)、DASH、FLV/MPEG-TS 等流媒体协议，自动识别多清晰度源。

AE 深度集成

实时获取 AE 项目信息：当前合成、文件夹树、图层结构。选择导入到项目根、指定合成、时间轴位置，支持预合成包装和 SVG 形状转换。

智能图层管理

精准控制图层顺序（最上层 / 选中层之上 / 最下层）、时间范围（合成起点 / 播放头 / 选中层入点）、重复文件策略（跳过/覆盖/副本/询问）。

站点深度适配

11 个主流平台专属注入脚本，绕过前端反爬机制直接提取原始高清资源。YouTube 伪装 Android VR 调取所有清晰度，Bilibili 读取 playinfo API。

极简原生架构

纯 HTML/CSS/JS，无框架依赖。Manifest V3 标准，核心代码约 80KB，极速启动。Popup 与 Side Panel 共用同一前端，响应式适配。

// 04 — 快速开始

三步安装，即刻使用

浏览器扩展通过 Chrome Web Store 安装（或开发者模式加载），AE/PS CEP 扩展手动安装到 Adobe 扩展目录。

STEP 1

安装浏览器扩展

Chrome / Edge / Arc 等

从 Chrome Web Store 安装，或克隆仓库后在 chrome://extensions 中以开发者模式加载 browser-ext/ 目录。

# 克隆仓库（私有仓库需授权） git clone https://github.com/yancongya/NexusSnap.git # 在 chrome://extensions 中加载 browser-ext/ 目录
STEP 2

安装 AE/PS CEP 扩展

macOS / Windows

将 ae-cep-ext/ 目录复制或软链接到 Adobe CEP 扩展目录。macOS 路径：~/Library/Application Support/Adobe/CEP/extensions/。

# macOS：创建软链接 ln -s "$(pwd)/ae-cep-ext" \ "$HOME/Library/Application Support/Adobe/CEP/extensions/NexusSnap"
STEP 3

开始采集

体验完整工作流

打开 AE 或 PS → 浏览器浏览任意网页 → 点击扩展图标或 Ctrl+Shift+右键 呼出采集面板 → 选择媒体发送。

# 推荐工作流 1. 启动 After Effects（CEP 扩展自动加载） 2. 浏览器中打开 YouTube / Bilibili / 小红书等 3. 点击 NexusSnap 扩展图标查看嗅探到的媒体 4. 选中资源 → 选择 AE/PS 目标 → 发送 # 或使用快捷采集：Ctrl+Shift+右键 → 即显面板

// 05 — 注意事项

兼容性与安全

浏览器兼容：支持 Chrome 88+、Edge 88+、Arc 及其他 Chromium 内核浏览器。Firefox 暂不支持（Manifest V3 差异）。

Adobe 版本：After Effects 22.0+ (AEFT)、Photoshop 23.0+ (PHXS)。需启用 CEP 调试模式（PlayerDebugMode 设为 1）。

隐私：所有数据处理在本地完成，媒体直接通过 WebSocket 发送到本地 AE/PS，不上传任何服务器。站点专属适配器仅在对应页面激活，不会收集浏览数据。
