快速开始

下载安装，即刻使用

1 安装浏览器扩展

CHROMIUM · ZIP

适用于 Chrome、Edge、Arc 等 Chromium 浏览器。下载并解压后，手动加载扩展文件夹。

  1. 打开 chrome://extensions
  2. 开启右上角开发者模式
  3. 点击加载已解压的扩展程序
macOS 首次安装

如果系统阻止加载，请对解压文件夹执行 xattr -dr com.apple.quarantine 文件夹名。

2 安装 AE/PS CEP 插件

ADOBE CEP · ZIP

适用于 After Effects 与 Photoshop。将解压后的插件文件夹放入 Adobe CEP 扩展目录。

  1. 复制 NexusSnap-CEP 文件夹
  2. 启用 PlayerDebugMode = 1
  3. 重启 AE 或 Photoshop
查看 CEP 安装路径
# macOS CEP 扩展目录 ~/Library/Application Support/Adobe/CEP/extensions/ # Windows CEP 扩展目录 C:\Program Files (x86)\Common Files\Adobe\CEP\extensions\ # 放入后确保 PlayerDebugMode = 1（启用 CEP 调试）

3 开始采集与导入

启动 After Effects 或 Photoshop → 浏览任意网页 → 点击扩展图标查看嗅探媒体并选中发送；或 Ctrl+Shift+右键 呼出快捷采集面板，长按发送打开 Action Orbit 精确路由。

兼容性

环境要求

浏览器

Chrome 88+、Edge 88+、Arc 及其他 Chromium 内核浏览器。Firefox 暂不支持。

After Effects

AE 22.0+ (AEFT)，需启用 CEP 调试模式（PlayerDebugMode = 1）。

Photoshop

PS 23.0+ (PHXS)，支持图片与 SVG 导入，智能对象或像素图层两种模式。

隐私

所有数据本地处理，媒体通过本地 WebSocket 传输，不上传任何服务器。
