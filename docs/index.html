工作流

三步：发现 → 选中 → 发送

不需要下载、找文件、拖拽。在网页上看到任何媒体素材，直接发送到你的创作工具。

智能嗅探，自动发现

浏览器扩展自动扫描页面 DOM 中的图片、视频、音频元素，同时通过 webRequest API 拦截网络请求，捕获 AJAX/XHR 加载的隐藏媒体 URL。内嵌 hls.js 和 mpegts.js 解析 HLS、DASH、FLV 等流媒体协议，自动识别多清晰度源。

快捷采集，即时预览

Ctrl+Shift+右键 呼出采集面板——左侧预览媒体内容和元数据（尺寸、格式、时长、分辨率），右侧选择发送目标和导入选项。支持 HLS 直播流实时预览播放，批量采集一次性发送多资源。

一键导入，开始创作

通过本地 WebSocket 通信，将素材直接导入 After Effects 或 Photoshop。实时获取 AE 项目结构，精准控制图层位置、时间范围、预合成包装。支持重复文件策略（跳过/覆盖/副本/询问）、SVG 形状转换等高级选项。

快速开始

下载安装，即刻使用

1 安装浏览器扩展

下载 .zip 压缩包，解压后在 chrome://extensions 页面开启「开发者模式」，点击「加载已解压的扩展程序」，选择解压后的文件夹即可。支持 Chrome / Edge / Arc 等 Chromium 内核浏览器。

下载浏览器扩展 (.zip)

macOS 用户下载后解压，在终端执行 xattr -dr com.apple.quarantine 解压后的文件夹名 以去除安全隔离标记。

2 安装 AE/PS CEP 插件

下载 CEP 插件包，解压后将整个文件夹放入 Adobe CEP 扩展目录。需要先启用 CEP 调试模式（PlayerDebugMode = 1）。

下载 CEP 插件 (macOS) 下载 CEP 插件 (Windows)
# macOS CEP 扩展目录 ~/Library/Application Support/Adobe/CEP/extensions/ # Windows CEP 扩展目录 C:\Program Files (x86)\Common Files\Adobe\CEP\extensions\ # 放入后确保 PlayerDebugMode = 1（启用 CEP 调试）

3 开始采集与导入

启动 After Effects 或 Photoshop → 浏览器浏览任意网页 → 点击扩展图标查看嗅探到的媒体 → 选中资源发送。或使用 Ctrl+Shift+右键 呼出快捷采集面板。

兼容性

环境要求

浏览器

Chrome 88+、Edge 88+、Arc 及其他 Chromium 内核浏览器。Firefox 暂不支持。

After Effects

AE 22.0+ (AEFT)，需启用 CEP 调试模式（PlayerDebugMode = 1）。

Photoshop

PS 23.0+ (PHXS)，支持图片和 SVG 导入，智能对象或像素图层两种模式。

隐私

所有数据本地处理，媒体通过本地 WebSocket 传输，不上传任何服务器。
