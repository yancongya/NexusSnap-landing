NexusSnap 隐私政策 / Privacy Policy

生效日期 / Effective date: 2026-08-14

1. 适用范围 / Scope

本政策适用于 NexusSnap 浏览器扩展。扩展用于识别用户访问页面中的媒体资源，并按用户指令下载素材或将其发送到本机运行的 NexusSnap Adobe CEP 面板。

This policy applies to the NexusSnap browser extension. The extension identifies media resources on pages the user visits and, at the user's request, downloads them or sends them to the NexusSnap Adobe CEP panel running on the same device.

2. 处理的数据 / Data processed

为提供媒体识别功能，扩展会在本地处理当前页面的 URL、DOM 中的媒体信息、网络请求元数据，以及媒体 URL、文件名、格式、尺寸、分辨率和时长。扩展还会在浏览器本地存储用户设置、访问授权状态和界面偏好。

To detect media, the extension locally processes the current page URL, media information in the page DOM, network request metadata, and media URLs, file names, formats, sizes, resolutions, and durations. It also stores user settings, local access authorization, and interface preferences in browser storage.

3. 数据使用与传输 / Use and transfer

NexusSnap 不会把浏览历史、页面内容、媒体 URL、用户设置或下载文件发送到 NexusSnap 运营者的服务器。扩展不包含分析、广告或用户追踪 SDK。

NexusSnap does not send browsing history, page content, media URLs, user settings, or downloaded files to servers operated by NexusSnap. The extension contains no analytics, advertising, or user-tracking SDK.

某些站点需要扩展在用户已登录的网页上，使用用户当前站点会话请求该站点自身的媒体。这些请求只发送给用户正在访问的站点，不会发送给 NexusSnap 运营者。

On some signed-in sites, the extension may use the user's existing site session to request media from that same site. Those requests are sent only to the site the user is visiting, not to the NexusSnap operator.

当用户主动选择 Adobe 导入时，选定的媒体信息会通过 localhost WebSocket 发送到同一设备上的 NexusSnap CEP 面板。

When the user chooses Adobe import, selected media information is sent through a localhost WebSocket to the NexusSnap CEP panel on the same device.

4. 共享、出售与目的限制 / Sharing, sale, and purpose limitation

NexusSnap 不出售用户数据，不为广告、信用、借贷或与扩展单一用途无关的目的使用数据，也不向第三方数据经纪商提供数据。

NexusSnap does not sell user data, use it for advertising, credit, lending, or purposes unrelated to the extension's single purpose, or provide it to third-party data brokers.

5. 保留与删除 / Retention and deletion

媒体检测结果为当前浏览会话中的本地工作数据。用户可在扩展设置或浏览器的扩展数据管理界面清除本地设置和授权状态；卸载扩展也会移除由浏览器管理的扩展本地数据。

Detected media is local working data for the current browsing session. Users can clear local settings and authorization through extension or browser extension-data controls. Uninstalling the extension removes extension-local data managed by the browser.

6. 联系 / Contact

如有隐私问题，请通过 NexusSnap 支持页面 联系我们。

For privacy questions, contact us through the NexusSnap support page.
