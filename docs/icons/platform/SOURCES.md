# Platform logo sources

These files are locally vendored so the landing page does not depend on third-party requests at runtime.

- `youtube.svg`, `bilibili.svg`, `xiaohongshu.svg`, `instagram.svg`, `x.svg`, `pinterest.svg`, `reddit.svg`, `sinaweibo.svg`, `taobao.svg`: downloaded from the corresponding [Simple Icons](https://simpleicons.org/) brand entries.
- `jimeng.ico`: the favicon declared by the official [Jimeng](https://jimeng.jianying.com/ai-tool/home) page.
